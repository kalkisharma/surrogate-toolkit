# Compliance Guide

**Version:** v3.0.0 | **Last updated:** 2026-05-20

Documents the classification, watermarking, and audit trail features implemented in Phase 11.

---

## Classification levels

The toolkit supports four classification levels, configurable per session:

| Level | Code | Watermark color | Requires confirmation |
|---|---|---|---|
| Unclassified | `Unclassified` | Green | No |
| Controlled Unclassified Information | `CUI` | Blue | No |
| International Traffic in Arms Regulations | `ITAR` | Red | **Yes** |
| Export Administration Regulations | `EAR` | Red | **Yes** |

### Setting classification

Classification is set in the **Export** panel (Step 14) via the classification selector. The selected level is stored in `STATE['compliance']['classification']` and applied to all exports generated in that session.

### ITAR/EAR acknowledgment gate

When ITAR or EAR is selected, the **Generate Report** button is disabled until the engineer explicitly checks an acknowledgment checkbox. The checkbox text reads:

> "I acknowledge this report contains ITAR/EAR-controlled data and I am authorized to generate and distribute it under applicable regulations."

This acknowledgment is logged in the audit trail.

## HTML reports

Reports are generated by `POST /api/export/report` and returned as a file download.

### Report contents (adaptive)

Each section is included only if the corresponding workflow step was completed:

| Section | Included when |
|---|---|
| Session metadata | Always |
| Dataset summary | Dataset loaded |
| Column designation | Designation completed |
| Normalization | Normalization applied |
| Model configuration | Model trained |
| Test metrics + parity plots | Model trained |
| Sensitivity analysis | Interpret step run |
| Active learning history | Active learning run |
| Audit trail | Always |

### Classification watermark

Every report has a fixed banner at the top and bottom of the page with the classification level and appropriate color coding. The banner is styled to remain visible when printing (`@media print`).

### Report filename format

```
surrogate_report_<CLASSIFICATION>_YYYYMMDD_HHMMSS.html
```

Example: `surrogate_report_ITAR_20260515_143022.html`

### Self-contained format

Reports embed Plotly.js (CDN) and all chart data as inline JSON. The file has no external dependencies beyond an internet connection for the Plotly CDN. Charts are interactive in-browser and can be exported to PNG using the Plotly toolbar.

## Audit trail

All significant session events are logged in `STATE['audit']['events']`, capped at 1,000 entries (oldest events are dropped when the cap is reached).

### Export audit log

Export events are additionally logged in `STATE['compliance']['export_log']` with:

| Field | Description |
|---|---|
| `timestamp` | UTC ISO 8601 timestamp |
| `filename` | Report filename |
| `classification` | Classification level at time of export |
| `acknowledged` | Whether ITAR/EAR acknowledgment was checked |
| `sha256` | SHA-256 hash of the exported HTML bytes |

### Downloading the audit log

`GET /api/export/audit` — downloads the export log as a CSV file.
`GET /api/export/log` — returns the export log as JSON.

## Supported classifications (settings.py)

```python
SUPPORTED_CLASSIFICATIONS = ['Unclassified', 'CUI', 'ITAR', 'EAR']
DEFAULT_CLASSIFICATION     = 'Unclassified'
```

To add a new classification level:
1. Add it to `SUPPORTED_CLASSIFICATIONS` in `config/settings.py`
2. Add watermark and guidance entries in `app/compliance/classification.py`
3. Decide if it requires confirmation and update `requires_confirmation()`
